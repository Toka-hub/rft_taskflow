# TaskFlow – kezdeti backlog (vázlat)

Első heti, durva lista. A 2. héten pontosítjuk, elfogadási feltételeket és prioritást kapnak.

| Issue | Rövid leírás |
|-------|--------------|
| chore: Projektváz előkészítése | Mappaszerkezet és egy lokálisan elindítható induló projekt. |
| docs: Telepítési és indítási útmutató | README-ben leírni, hogyan lehet klónozni és elindítani a projektet. |
| feature: Feladatok felvétele és listázása | Új feladat létrehozása és a projekt feladatainak megjelenítése. |
| feature: Feladat állapota és felelőse | Állapotváltás (Teendő → Folyamatban → Kész) és csapattag hozzárendelése. |
| tech: Technológiai stack kiválasztása | Lehetséges technológiák összegyűjtése a későbbi döntéshez. |
